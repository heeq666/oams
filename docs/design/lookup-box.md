# lookup_box（查件框）形态 · 2026-11-01

**一句话**：一个叶子模块——输入单号，就地显示**本页条目里**的那一条只读小卡；查不到就说一句「本页没有这个单号」，未输入就说一句怎么用。**不参与汇总，不跨页，不查别的部门。**

这份是**形态稿**（只定长什么样、说什么话、算不算数），不含实现。跟 `design-system-v1.md` §6 的模块层同口径：块面圆角 18（`radius/control`）、`bg/surface` + 1px `border/default`、内距 16、无阴影、间距只用 8/12/16。

## 1. 形态

- **叶子**：不带 `children`（容器才有子件），也不套 `.card`——它自己就是一块模块块，跟 `.wh-m` 那批（加上它自己共 21 件）同级。
- **内部纵向三件**：输入行（`Search`，30 高、内距 0·12、圆角 **18**）+ 查询按钮（30 高、胶囊 **999**，按钮那一档才给 999）+ 结果区。行与行 8，结果区与输入行 8；块与块对外 16。
- **为什么输入框不写 999**：999 那一档给的是外壳搜索框（`Search` 40 高）；模块块里这个输入跟同排的字段行是一层，走 `radius/control` 18（`design-system-v1.md` §3）。
- **三态，每态一句人话**，都用一行 `.wh-empty`（13px、`--oams-muted`、`margin:0`、句末带句号），不画空框、不画骨架、不用 `—` 撑（§6「内容为空时一律一行灰字」）：

| 态 | 触发 | 那一行写什么 |
| --- | --- | --- |
| 未输入 | 页面刚打开、输入框空 | 「输入单号后在这里看结果。」 |
| 命中 | 查到唯一一条 | 不出文字，出只读小卡（见 §2） |
| 查无此件 | 本页条目里没有这个单号 | 「本页没有这个单号。别跨页找——这个框只看当前这一页。」 |

- 命中多条时：卡照出，下面补一行灰字「同一个单号有多条，这里显示最新的一条。」

## 2. 命中态：只读小卡显示什么

四个字段，**全部从标准字段词表里映射**（`app/oams/modules.py:38-61`），不新造键：

| 卡上 | 来源标准字段 | 写法 |
| --- | --- | --- |
| 单号 | `order_no` | 原样字符串，13px |
| 状态 | `status` | 落四态中文（计划中 / 进行中 / 阻塞 / 已完成），不印 `in_progress` 这种内部词 |
| 到件日 | `completed_at`（已到件）或 `due_at`（还没到，标签写「预计到件」） | 只到日 `YYYY-MM-DD`，不带时分 |
| 取件点 | **暂借 `note`** | 词表里没有「地点」这类字段；要独立键得先改冻结词表（**已知限制，见 §8**） |

中性示例（写进文档、截图、测试夹具都用这一组，**不写客户名/真人名**）：单号 `AW26-001`、状态「已完成」、到件日 `2026-11-01`、取件点「一楼前台」。

小卡本身不再套一层描边：卡里已经有一个 18 圆角的面，里面再来一个框就成了框里套框。四行用「标签 12px `--oams-muted` + 值 13px」两列排，行距 8。

## 3. 无指标：不参与任何聚合

- 注册表那行写 **`aggregatable=False`**（跟 `evidence_gallery` 同一种含义：本部门可见、不进公司汇总），不声明 `metric_key`，不 `produces` 任何标准字段。
- **跟 `metric_card` / `metric_grid` / `status_chart` 互不影响**：那三件读的是 `dept.<部门代码>.<指标键>` 聚合与字段计数；这个盒子查出的一条不增加任何数字，指标块里的数字也不因为盒子里没查而变 0。一句话：**盒子是查询工具，不是数据源**。
- 两处代码后果，写下来免得后面当 bug 报（都在 `app/oams/render.py`，属后端写区）：
  1. **填报/编辑视角**：`private_note`（`:689-697`）会给 `aggregatable is False` 的件多印一行「本部门可见，不参与公司汇总」——对查询件这句话读着别扭。**拍板（2026-11-01）：这一行只给录入件，查询件跳过**（列入 §5 第 4 条）。
  2. **只读视角**：`_hidden_in_readonly`（`:807-815`）会把 `aggregatable is False` 的叶子**整块剔除**，公司/上级看到的页面里没有这个盒子。**接受**——查询是填的人自己用的工具；审核看的是这页的定义，走 preview 视角，控件仍在场、`disabled`。
- **别为了「只读也想看」把它改成 `aggregatable=True`**：那会把它算进汇总口径，正好是本条要防的事。**也不要在 `_hidden_in_readonly` 里给它开按类型放行的口子**——2026-11-01 拍板：整块剔除就是想要的效果（§5 第 4 条）。

## 4. 数据源：只读本页

- 查**这一页整页口径**的条目：与列表、数字、状态统计同一个口径（`PAGE_ENTRY_SCOPE_SQL`，`app/oams/api.py:1030`；读方 `_binding_entries`（`:1160`）与 `page_entries`（`:1189`））——**记在更早那一版的条目，仍然是这一页的条目**；不按 `slug` 跨页，也不另按版本过滤。
  - 2026-11-01 改口：原口径是「查当前打开的这一版自己的条目、不按 slug 跨版本」（各查各的，跟工作台「一个页签一版」一致）。改的理由一句话——**表格里看得见的行，查件框却报「本页没有这个单号」，用户会判成「查询坏了」，而不是「版本不同」**。代码 `16f3e6b`。
- **命中更早版本的条目时，结果卡要注明**「这条记在更早的那一版上」：字段值按**当前这一版**的 descriptor 映射，老条目里没有的字段就留空——不说这一句，读到空字段的人会以为数据丢了。用现成的 `.wh-meta`（和「另外还有 N 条同号」同一层），不新增样式；模板 `f8ef72f`（`hit.older`）。
- **不跨页**：不 join 别的 `interface`、不读公司汇总表、不调平台指标接口。
- **不查别的部门**：路由挂在部门工作台那一族下，权限沿用同一套部门守卫（无权限就是现有的 403 / 303），盒子自己不判权限、不提前渲染别人的数据。
- **页面加载不预查**：渲染时只出输入行与「未输入」那句；**空输入不发请求**（前端拦，别靠后端回空态）。

## 5. 契约面清单（只列名，不实现；各自归写区）

1. `docs/architecture/p0-interface-contract.md` §1 —— **先加一行**。`app/oams/modules.py` 的注册表 docstring 写着「adding a module means adding a row to the contract first」，注册表跟着从 20 个 key 变 21。→ **已落**：契约 `49d2d88`、模块 `4506cc7`，注册表实测 **21 个键**。
2. `app/oams/modules.py` —— `_register(_spec("lookup_box", "查件框", "display", …, params={"key_field": _param("str", default="order_no")}, consumes=("order_no","status","completed_at","due_at","note"), produces=(), aggregatable=False))`。
3. `app/oams/descriptor.py` —— 三条校验：① `key_field` 必须在 `STANDARD_FIELD_VOCAB` 里；② 它读的这几个字段必须**已被本页某个录入件映射**（否则永远查不到东西，给 `DATA_RULE_VIOLATION`，别让作者上线后才发现）；③ 叶子规则：`display` 层不许 `children`（现有容器规则按 layer 判，顺带就挡）。
4. `app/oams/render.py` —— 一个 `lookup_box(module)` 渲染函数 + 分派表一项；**`private_note` 跳过查询件**（§3，2026-11-01 拍板：那句「本部门可见，不参与公司汇总」是给数据来源用的，查询框不是数据来源，多印一行读者会以为它在报数）；`_hidden_in_readonly` 保持原样——只读视角整块剔除已拍板接受，别按类型放行。
5. `app/oams/templates/modules/lookup_box.html`。
6. `app/oams/static/oams-modules.css` —— 新增一节 `.wh-m.wh-lookup`，**双类名**（`.wh-m.wh-input` 那次单类名连外壳一起命中的教训，`design-system-v1.md` §8.2）。
7. `app/oams/web.py` —— 一个 partial 路由：`GET /departments/{org_unit_id}/{interface_id}/lookup?q=<单号>`，命中回小卡、没有回一行空态；只有带 `HX-Request` 才回片段。
8. **要不要「取件点」独立字段**：词表是冻结的（`modules.py:38-61`），现在借 `note`。真要做独立键，得改词表 + 契约，属后端与契约的事——**本轮不申请**。

## 6. 验收口径

- **三档**：1440 / 1024 / 768 各一次，`document.documentElement.scrollWidth === clientWidth`、越界元素 0；盒子在 1440 下撑满所在列（并排时 704），圆角 18、内距 16。
- **三张图**：未输入 / 命中 / 查无此件，各一张（自检图落 `/tmp/lookup-{empty,hit,miss}-<宽>.png`；要进文档的才另存 `docs/assets/`）。
- **空输入不发请求**：输入框空着点查询，网络记录里**没有** `/lookup` 这条（断言 `0` 条，不是断言回了个空态）。
- **只回本页**：塞一条 `LOOKUP-LEAK-PROBE` 到别的页面，partial 响应里 0 命中；直开 `/lookup?q=` 不带 `HX-Request` 时回整页工作台，不回裸片段。
- **不影响数字**：同一页加这个盒子前后，部门工作台的 `dept.*` 聚合与条目计数**一个数都不变**（`aggregatable=False` 的机器判据）。
- **权限**：无该部门读权限的账号 → 403/303，跟页面上其他入口同一套判定。

## 7. 一句话取舍（留给后面看的人）

快递页这轮先走「台账 + 页内查找」的 A 案（台账是录入件，能进汇总），这个盒子是**下一件功能**：它让演示里那一页**能真查**，而不是只有一排条目。等它做出来，`ga-parcel-lookup` 从「只有台账」变成「台账 + 输入单号看结果」，正好对上老大举的那个例子。

## 8. 已知限制（写下来，别当 bug 报）

- **「取件点」目前用 `note` 承载**：语义上它应该是独立的「地点」字段，现在是借字段。等标准字段词表（`app/oams/modules.py:38-61`，冻结的）变更时一并改，别在业务层自己造键。收尾清单里挂了一条（`module-refinement-checklist.md` §6）。
- **只读视角看不到这个盒子**：`aggregatable=False` 的必然结果，已拍板接受（§3）；公司/上级看到的页面里它就整块不存在。
- **同一单号多条取最新一条**：只补一行说明，不做「选哪条」的交互——那是另一个模块的事。
