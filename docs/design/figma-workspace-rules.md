# Figma 文件规约（company-os）

> 一个 Figma 文件、三张页面。这是硬约束：**当前是 Starter 计划，最多 3 张页面**，第 4 张会直接报错。所以页面不能靠「多开一张」来分类，只能靠「一页一个职责 + 页内分区 + 命名」。
>
> 本规约 2026-10-29 立的，起因是用户一句话：『我看 figma 里乱七八糟的，01 设计令牌是什么东西？组件库里应该放的是组件啊，怎么有页面的东西，页面稿里应该是正式页面啊，怎么还有草稿。』

## 1. 三张页面，各管一类东西

| 页面 | 放什么 | 不放什么 |
| --- | --- | --- |
| `01 · 规范 Specs` | 令牌表（颜色 / 圆角 / 间距 / 字号 / 断点）、状态矩阵、栅格模板、滚动时序这类**规则的可视化** | 组件、页面稿、草稿 |
| `02 · 组件 Components` | 只有组件：`COMPONENT` / `COMPONENT_SET` / 分区 `FRAME` / 说明 `TEXT` | 页面稿、游离图形、散落的实例、旧稿 |
| `03 · 页面 Pages` | 只有**能对着真实路由跑的页面**，一页一个 frame | 规格板、矩阵、模板、草稿 |

判断归属只问一句：**这东西是「规则」、「积木」还是「成品」？** 规则进 01、积木进 02、成品进 03。三边都不像的，就是该删的。

## 2. 命名

- 页面：`01 · 规范 Specs` / `02 · 组件 Components` / `03 · 页面 Pages`（编号 + 中文 + 英文，一眼知道顺序与职责）。
- 页面稿共四类，一个模式（视口必写、状态缺省不写、分隔符统一 ` · `）：
  - 成品：`页面 · 汇报中心 /board · 1440`
  - 状态：`页面 · 汇报中心 /board · 1440 · 协作室展开`
  - 子页：`页面 · 汇报中心 /board ▸ 会话详情 /board/<id> · 1440`
  - 草稿 / 试验 / 历史：`草稿 · 汇报中心 /board · 1440 · 10-30`、`试验 · H1 · 协作室双栏 vs 三栏`、`历史 · 2026-10-28`
- 组件：中文名 + 英文关键字，例 `Button 按钮`；组件集内部变体属性一律中文（`变体=主要`、`状态=悬停`）。
- 分区：`骨架层 Shell` / `组件层 · 控件 / 反馈 / 数据` / `浮层 · 气泡 / 菜单 / 弹窗` / `协作室 · 底部两栏弹层` / `模块层 · 与 MODULE_REGISTRY 对齐`。
- 说明文字：`说明 · xxx`、`标题 · xxx`，统一前缀，方便在大纲里筛出来。

## 3. 组件页（02）的硬规则

1. **只有组件**。页面稿、矩阵板、草稿一律不许出现——这是这轮最脏的地方：页面上曾有 11 个游离矩形 + 1 个游离实例（某个菜单草稿被拖出来的残骸），以及一个 25 个节点的「归档 · 旧骨架说明」旧板块。
2. **不许有游离图形**。组件页上的所有东西必须挂在某个分区 frame 里；用 `figma.createXxx()` 建东西时它在当前页根上，**建完必须 `appendChild` 到分区**，中途报错也要清掉（本轮就抓到过 `140:4367/140:4368/140:4370` 这类残件）。
3. **实例只出现在「用法」卡里**。散落的实例（哪怕只有一枚 Badge）一律删掉——它不对应任何页面，只会让人以为漏了什么。
4. **分区顺序固定**：骨架 → 控件 → 浮层 → 协作室 → 模块。新分区插进这条链里，不许追加到最末。
5. **每个组件必须有 description**：写对应 `wh-*` 类名、语义（FILL / 定宽）、以及使用禁区。
6. **任何一次批量搬动之后跑一遍审计**：宽度、圆角、间距、文字样式、填充是否还绑着变量。

## 4. 页面页（03）的硬规则

1. **一页一个 frame，1440 / 1024 / 768 三档各一个**，不许把两档塞进一个 frame。
2. **只放正式页面**。状态矩阵、滚动时序、12 栅格模板这类东西不是页面（这轮已全部迁到 01）。
3. **一行一个页面族，列位固定**：竖向是页面族，向右是视口与状态，向左是候选与档案。列距固定 1520、行距 = 本行最高 frame + 240，全套规则见 §4.1。
4. 页面稿里的颜色 / 圆角 / 间距 / 字号**只允许引用变量与样式**，不许裸值。

## 4.1 页面稿的坐标轴（2026-10-29 定）

四个维度全部落成坐标，不靠命名去猜。**原点 0 是定稿边界**：x ≥ 0 只有定稿，x < 0 只有候选与档案。

| 轴 | 表达什么 | 规则 |
| --- | --- | --- |
| Y+ | 页面族（一个路由一行） | 行首族标题 `F03 · 汇报中心 /board`（Heading/H1），frame 从 y+60 起；行距 = 本行最高 frame + 240 |
| X+ | 成品细度 | C1 主态 1440 → C2 1024 → C3 768 → C4 起子页 `▸` → 其后该页特有的状态；列距固定 1520 |
| X− | 离定稿的距离（成熟度梯子） | −1520 对比 B → −3040 对比 A → −4560 草稿 1 → −6080 草稿 2 → −7600 / −9120 / −10640 试验 A/B/C → −12160 档案 |
| 边界 | 哪边能放什么 | 主竖线 x=−80（过去 | 定稿）；第二竖线 x=−10680（候选 | 档案）。跨线即违规 |

**固定档位**（坐标写死，加内容不会让别的稿子挪动）：

| 档位 | x | 放什么 | 上限 | 怎么退场 |
| --- | --- | --- | --- | --- |
| 对比 B | −1520 | 提案版，等拍板 | 1 | 签了 → 改动落进正轴成品，删 |
| 对比 A | −3040 | 现网版，从正轴复制，永远在 B 左边 | 1 | 评审结束即删 |
| 草稿 1 / 2 | −4560 / −6080 | 目标明确的局部改法 | 各 1 | 直接替换成品，删 |
| 试验 A/B/C | −7600 / −9120 / −10640 | 同一假设的布局变体，动的是结构 | 1 组≤3 | 选定后落成草稿/成品，其余导图存档后删 |
| 档案 | −12160 | 上一版定稿快照，回滚用 | 1 | 被新版顶替时导 PNG 存档后删 |

**草稿和试验的界线**（最容易糊的一条）：

| | 草稿 | 试验 |
| --- | --- | --- |
| 动什么 | 局部：文案、间距、某个块的位置 | 结构：栏位增减、栅格重排、信息层级 |
| 方向 | 已定，只剩执行 | 未定，本身就在问「该不该这么做」 |
| 几张 | 1 张 | 必须 2–3 张并排，单个变体不算试验 |
| 产出 | 直接替换成品 | 挑一个变成草稿 → 成品，其余导图存档 |

配套约束：

- 试验组上方必须有「假设牌」：待验证问题 + 判据 + 日期。没有假设牌的试验组算违规。
- 结论要留痕：删之前把变体导进 `assets/review/<日期>-exp-H<编号>/`，并在 `design-system-v1.md` §8.2 写一句结论。
- 负轴全是复制品，**不许被外部实例引用**；母版永远是 x ≥ 0 的那张。
- 每个 frame 上方有 caption（`C4 · 1440 · 协作室展开`），12 Medium `text/muted`，用来扫列。
- 清理节奏：评审结束清空对比 A/B 与草稿；试验组一周不推进就删或升格。
- 归属判断：只变了顶栏 / 按钮 / 组件外观 → 归 01 状态矩阵；内容区栅格、栏宽、栏的有无变了 → 才算页面级状态，占 03 一列；弹层 / 抽屉 / 右键菜单 → 归 02 浮层分区，不出页面稿；通用空 / 加载 / 错误三态 → 只在 01 出一次。

## 5. 归档

- 这个文件只有三页，**没有第四张「归档」页**。废弃的东西走两条路：
  - **导出 PNG 存档**（`.figma/assets/` → `assets/review/<日期>-figma-reorg/`），然后从画布上删掉。
  - 确实要留的，放 02 页最左侧、与主库保持 1000px 以上间距，名字以 `归档 · ` 开头。
  - 页面稿的旧版本不进 02，走 03 的负轴档案位（x=−12160，最多 1 张，见 §4.1），名字以 `历史 · ` 开头。
- 本轮按这条路删掉了 `128:3402 归档 · 旧骨架说明`（25 个节点：旧库文字标签 + 一枚仍在服役的 `3:169 Metric card`）。**删之前先把 Metric card 迁进「数据展示」分区**（它当时挂在归档帧里，全库 66 个实例在用）。PNG 存档见 [90-归档旧骨架-已删除前存档.png](<assets/review/2026-10-29-figma-reorg/90-归档旧骨架-已删除前存档.png>)。

## 6. 自查清单（改完照着念一遍）

- [ ] 组件页：`page.children` 里只有分区 frame，没有 `RECTANGLE` / `INSTANCE` / `TEXT` 裸节点。
- [ ] 页面页：每个 frame 名字都是 `页面 · …`，宽度是 1440 / 1024 / 768 之一。
- [ ] 页面页坐标轴：x ≥ 0 里没有草稿 / 对比 / 历史，x < 0 里没有成品；列距是 1520 的整数倍，行距 = 最高 frame + 240。
- [ ] 页面页标注：每行有 `F0x ·` 族标题，每个 frame 上方有 `Cx · 视口 · 状态` caption。
- [ ] 规范页：令牌表的色块都绑着变量（不是手填色值）；字号示例都绑着 text style。
- [ ] 全库：圆角只有 4 / 9 / 18 / 26 / 999；间距只有 4 / 8 / 12 / 16（模块层内部），页面级 24 / 32 / 64。
- [ ] 任何组件改完，导一次 PNG 看图，再用 `use_figma` 回读关键数值（图会骗人，数值不会）。
