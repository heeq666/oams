# 模块层细化清单（20 个模块 × 缺什么）

> 状态：**待拍板**。规则先写进本文（或本清单），定了再动代码（顺序见 §4）。
> 取证范围：`app/oams/templates/modules/*.html`（20 个 / 315 行）、`app/oams/static/oams-modules.css`（682 行）、`app/oams/render.py`、`tests/test_render_modules.py`。

## 0. 一句话结论

模块层现在**只有一种状态：填满态**。14 个模块此前各只有一份「填满」稿（单帧、宽 700 固定、无变体；2026-10-30 已统一到内容宽 704 + 填报 / 只读两形态）；代码 20 个模板平均 15 行，只有 5 个有空态、6 个分视图、0 个有图标。缺的不是样式，是三件事：**视图（三档 → 实际两档）、状态（空 / 不全 / 失败）、边界（0 行 / 1 行 / 超长 / 缺字段）**。

## 2. 三个口径（这三个定了，20 条才有落点）

### 2.1 三视图各自是什么

| 视图 | 谁看 | 应该长什么样 | 现在的样子 |
| --- | --- | --- | --- |
| `edit` 填报 | 填这页的岗位 | 控件 + 我的值 + 私有提示（本部门可见） | 有，基本可用 |
| `preview` 审核 | 部门管理员 / 平台 | **可填形态 + 示例值 + 右上角「进汇总 / 不进汇总」角标**，控件禁用不可填 | 只读 + 角标，**看不到控件长什么样** |
| `readonly` 只读 | 上级 / 汇总 | 只读 + 剔除私有件（`evidence_gallery` 现在被整块丢掉） | 有，但和 preview 同形 |

**要拍的两条**：

1. preview 是「可填形态」还是「只读 + 角标」？现在代码里两处自相矛盾——`render.py:51` 写着 `INLINE_MODES = ("edit", "preview")  # modes in which a module may show <input>`，而 `tests/test_render_modules.py:247 test_preview_never_renders_a_widget` 断言 preview 里不许出现控件；`INLINE_MODES` 这个常量**全仓没有任何引用**（grep 只命中定义本身）。两条只能留一条。
   **我的建议**：留 `INLINE_MODES` 的本意——preview 走控件分支，控件加 `disabled tabindex="-1"`，值用 `render_preview(sample=True)` 的假值，测试改成「preview 里控件必须 disabled」。理由：审核审的是**这页的定义**（字段对不对、控件类型对不对、表列够不够），只读态看不出来；而且 `disabled` 不参与提交，安全性不降。
2. readonly 要不要保留 `evidence_gallery`？现在是整块剔除（`render.py` 的 `_hidden_in_readonly`）。**我的建议**：保留，只读展示。理由：证据是审核的关键，上级看不到证据就只能看结论。

### 2.2 空 / 加载失败 / 数据不全

| 状态 | 定义 | 表现 | 文案 |
| --- | --- | --- | --- |
| 空 | 合法，但没数据（0 行 / 没绑定 / 没上传） | 一行 13 号 `text/muted`，模块高度不塌也不涨（≤48） | 统一句式「还没有 X。」，需要动作时后缀一句可点 |
| 不全 | 有数据，但字段缺（缺标题 / 缺日期 / 缺单位） | 占位文字，不隐藏整行、不报错 | 「未填写标题」「未排期」「—」 |
| 加载失败 | 取数失败 | **不下放到模块层** | — |

**要拍**：模块层不建「加载失败」态。理由是模块在服务端一次同步渲染，一次渲染里不存在「某个模块失败」；唯一会失败的是描述符配置错（缺列 / 未知 metric），那是 `check` 与 preview 的职责。硬造 20 个失败态 = 20 段永远不会执行的分支，还会让空态与失败态的视觉语言分叉。页面级失败统一交给 Alert（§6）。

**要拍**：空值符号统一 `—`（U+2014），不用 `--`；`0` 只表示零。要改 `aggregate` / `format_number` / `progress_percent` 三处。

### 2.3 图标

只上两类，不给每个模块配一枚语义装饰图标（那要新增 20 枚、还得让人记住图形词汇）：

| 用途 | Lucide | 位置 | 尺寸 |
| --- | --- | --- | --- |
| 新增一行 / 一个节点 | `plus` | 表尾整行按钮左侧；里程碑列表末尾 | 16 |
| 删除一行 | `trash-2` | 行尾，hover / focus 时显 | 16 |
| 证据外链 | `external-link` | 链接文字右侧（替掉 `↗` 字符） | 16 |
| 流程方向 | `arrow-right` | 流程条段与段之间（替掉 `&rarr;`） | 16 |

规格：24 网格、stroke 2、`text/muted`，与 13 号正文基线对齐（CSS 里 `vertical-align:-2px` 或 flex 居中）。**不拿字符当图标**（§5.1）。这 4 枚先补进 §5.1 的图标集，再在模板里内联同一份 path。

## 3. 20 个模块逐条

图例：✅ 已有 · ⚠️ 有但不合格 · ❌ 没有。

### 容器层（7）

#### 1. `card` 卡片 — 内容高 166

- **三视图**：三档同形（标题 + body）。❌ 缺：**body 为空时的形态**——现在照样渲染一个空 `.wh-card-body`，得到「只有标题的卡」或「纯灰空框」。
- **空 / 不全**：子件全空 → 整卡不渲染（连标题一起），别留空壳。标题缺 → 不渲染标题行（✅ 已实现 `if title`）。
- **图标**：不要。卡片标题是文字，不是导航。
- **边界**：标题超长 → 单行省略 + `title` 属性；子件 1 个 / 8 个都靠父 gap，不自己撑高。
- **形态**：须支持 2 个形态（有子件 / 空）。底色改回 `bg/surface` 白（G7），内距 16、圆角 18（✅ 与代码一致）。

#### 2. `tabs` 标签页 — 内容高 114

- **三视图**：三档同形。❌ 缺：**真正能切的标签页**。现在是 `tabs.html:6` 一条不可聚焦、不可点的 `<span role="tab">`（`aria-selected` 永远第一枚），下面 `tabs.html:12-18` 是各自独立的 `<details>`，每个 `<summary>` 又把标签重复一遍 → 视觉上两套 UI 抢同一件事。
- **空 / 不全**：`labels` 多于子件 → 多出来的 chip 置灰 disabled（现在点不到也不报错，看起来像坏了）；`children` 多于 labels → 面板标「标签 N」（✅ 已有）。
- **图标**：不要。
- **边界**：labels ≤ 5 单行不换行（现在 `flex-wrap: wrap` 随时换行，5 枚 30 高胶囊在 700 宽里放得下）；> 5 才换行。
- **形态**：须支持 2 个形态（展开 / 收起）。
- **方案二选一**（拍板）：① radio + label 纯 CSS 标签页（无 JS，`input[type=radio]` 隐藏，靠兄弟选择器切面板）；② 认成手风琴，**删掉 tab 条**，只留 `<details>`。不要两套并着。

#### 3. `divider` 分隔线 — 内容高 27

- **三视图**：同形。
- **空 / 不全**：不适用（无数据）。
- **图标**：不要。
- **边界**：label 超长 → 单行截断（现在 `.wh-divider-label` 是 block，长标签会换行把线往下顶）。
- **形态**：不缺变体。

#### 4. `spacer` 留白 — 内容高 16

- **三视图**：同形（`aria-hidden` ✅）。
- **空 / 不全**：不适用。
- **图标**：不要。
- **边界**：⚠️ **首尾 spacer 会双倍留白**（父容器 gap 12 + spacer 32）。建议：容器首尾的 spacer 不渲染。
- **形态**：不缺变体。

#### 5. `columns` 分栏 — 无组件（规范 §6：排版结构不建）

- **三视图**：同形（不装数据）。
- **空 / 不全**：❌ 缺：子件全空时整块隐藏，别留 `.wh-cell` 空 div 占位（现在 `columns.html:7` 无条件渲染）。readonly 已有「子件全丢则整块丢」的逻辑，edit / preview 也要。
- **图标**：不要。
- **边界**：⚠️ 5 列退 1 列太狠（`oams-modules.css:115`）→ 改退 2 列；⚠️ 900px 一刀切（G12）→ 见拍板第 7 条。
- **形态**：无组件；以 §4 的 12 栅格（三档断点）为口径参照。

#### 6. `rows` 行 — 无组件

- 三视图同形；子件全空 → 整块隐藏；图标不要。
- 边界：gap 只有 sm/md/lg，`lg` 是 20（越档，G13）→ 收成 16。
- **形态**：无组件。

#### 7. `grid` 网格 — 无组件

- 三视图同形；子件全空 → 整块隐藏。
- ⚠️ **同行不等高**：`oams-modules.css:105` `align-items: start`，与 `layout-grid.md` 的「有底的面板同行等高」打架 → 有底子件改 `stretch`。
- 图标不要；`columns-3` 在 700 宽栏里每列约 217，够放一行指标卡。

### 录入层（6）

#### 8. `progress_row` 进度行 — 内容高 150

- **三视图**：edit = 标题 + 状态下拉 + 进度数字 + 依据 + 备注 textarea（✅ 有，`.wh-grid-2` 排）；readonly = 标题 + 状态徽章 + 百分数 + 备注 + 依据 + 进度条（✅ 有）；preview = ❌ 现在与 readonly 同形，看不到控件（G1）。
- **空 / 不全**：⚠️ **未填被说成 0%**（G4）：`progress_row.html:16` 拿 `progress_percent()` 拼 `%`，空值返回 0 → 进度条空、数字 0%，是假数据。改：空 → `—` + 空条（无填充、轨道灰）；标题缺 →「未填写标题」（✅）；依据缺 → 整行不出现（✅）。
- **图标**：不要装饰图标；依据若是外链，加 `external-link` 16。
- **边界**：备注超长 → 只读态 `pre-wrap` 全显（不折叠，模块高度交给页面）；百分数越界已被 clamp（✅）；⚠️ 百分数字号：规格初稿写 `Display/Metric 28`，代码 14 半粗（`.wh-num`）。30 行内放不下 28 → **代码保持 14，规格跟着改成 14**。
- **形态**：须支持 3 个形态（填报 / 只读·进行中 / 只读·未填）。

#### 9. `table` 明细表 — 内容高 97

- **三视图**：edit = 单元格内控件（⚠️ 见边界）；readonly = 静态文本（✅）；preview = ❌ 同 readonly。
- **空 / 不全**：❌ 两种空要分开——`columns` 空 = **描述符配置错**（preview / check 里说「缺列配置：这个表还没声明列」，edit / readonly 里整块不渲染）；有列无数据 =「还没有明细。」+「加第一行」（edit）。现在两者共用「这个明细表还没有配置列。」（G11），把开发者的话给了终端用户。单元格缺字段 → `—`（⚠️ 现在是 `&mdash;`，要统一）。
- **图标**：**需要**——`plus`（表尾「加一行」）、`trash-2`（行尾删除，hover 显）。
- **边界**：⚠️ 编辑态行高 42 vs 只读 30（G10）→ 单元格内联编辑（无边框、高 28、聚焦才描边），行高收回 30；`rows` 参数硬上限 5 → 到顶时表尾那一行换成「已有 5 行，更多请拆成两张表」（或放开到 10，拍板）；列 > 5 → 横向滚动（✅ `overflow-x`）；单元格超长 → 允许折行但给 `max-width: 320px`。
- **形态**：须支持 4 个形态（填报 / 只读 / 空 / 加行条）。

#### 10. `timeline` 里程碑 — 内容高 110

- **三视图**：edit = 里程碑列表 + 三个输入（`title` / `due_at` / `status`）；readonly = 固定项列表 + 我填的「下一条」；preview = ❌ 同 readonly。
- **空 / 不全**：❌ `items` 空且未填时只剩一行「未填写里程碑」，没有任何列表 → 补「还没有里程碑。」+「加第一个节点」；日期缺 → `未排期`（✅）。
- **图标**：`plus`（末尾加节点）。状态点用 7px 圆（✅ 已有，不用图标）。
- **边界**：`items` > 8 → 折叠「还有 N 个节点」；日期统一 `YYYY-MM-DD`（❌ 现在是自由字符串）；超长文本折行。
- **形态**：须支持 3 个形态（填报 / 只读 / 空）。

#### 11. `blocker_list` 阻塞清单 — 内容高 110

- **三视图**：edit = 4 个输入；readonly = 标题 + 状态徽章 + 原因 + 需要谁决策；preview = ❌ 同 readonly。
- **空 / 不全**：⚠️ 空态文案有（「当前没有阻塞。」）但用了**正文样式** `.wh-note`（13 号黑），不是 muted 空态 → 改 `.wh-empty`；`status` 缺 → 徽章 `—`（✅ 已 `&mdash;`）。
- **图标**：不要装饰；`status = blocked` 时标题左侧 2px `status/danger` 竖线（复用协作室 @ 提及的竖线语言），不加图标。
- **边界**：⚠️ **它只装一条阻塞**（单值绑定），名字叫 list 但行为不是清单——文档要写清「一个 blocker_list = 一条阻塞，多条靠 rows 堆」；原因超长 `pre-wrap`；需要决策超长单行省略 + `title`。
- **形态**：须支持 2 个形态（有阻塞 / 无阻塞）。

#### 12. `metric_input` 数值录入 — 内容高 56

- **三视图**：edit = 标题 + 数字 + 单位；readonly = 标题 + 格式化数值 + 单位；preview = ❌ 同 readonly。
- **空 / 不全**：⚠️ 未填显 `--`（G5）→ 改 `—` + 12 号 muted「未填」；edit 态给 `placeholder="0"`；单位必填（✅ `modules.py` 已要求）。
- **图标**：不要。
- **边界**：⚠️ 单位漂移——`.wh-inline` 里 `input` 是 `width:100%`（`.wh-input`），单位被挤到下一行 → 输入框改 `flex:0 1 160px`；大数字千分位（✅ `format_number`）；负数不允许（`min=0`）。
- **形态**：须支持 3 个形态（填报 / 只读 / 未填）。

#### 13. `evidence_gallery` 证据区 — 内容高 136
