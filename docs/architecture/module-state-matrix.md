## 1. 口径

### 1.1 三视图

| 视图 | 谁看 | 应该长什么样 |
| --- | --- | --- |
| `edit` 填报 | 填这页的岗位 | 控件 + 我的值 + 私有提示（本部门可见） |
| `readonly` 只读 | 上级 / 汇总 | 静态文本；**不进公司汇总的模块整块剔除**——`evidence_gallery` 是唯一一个（`aggregatable=False`，`app/oams/modules.py:249`），只读下不渲染（拍板 4，2026-10-30 改按代码） |
| `preview` 审核 | 部门管理员 / 平台 | **可填形态** + 示例假值 + 控件 `disabled tabindex="-1"`；**不带任何角标** |

preview 不是「只读 + 角标」——那套旧方案**整体作废**，不是只把只读换成可填。审核审的是**这页的定义**：字段对不对、控件类型对不对、表列够不够，只读态看不出来。`disabled` 不参与提交，安全性不降。

「进汇总 / 不进汇总」是 **descriptor 的属性**，不是模块长出来的东西：它出现在 `preview_descriptor` 返回的 `aggregates_preview` 里；**网页端目前没有预览页**，审核要看定义走 MCP 或 CLI，模块自身不画（2026-10-30 拍板，见 §5 第 6 条）。

### 1.2 八条拍板（2026-10-30 定）

1. 三视图 = 填报 / 只读 / preview（可填形态 + 假值 + 控件 disabled）。
2. **模块层不建「加载失败」态**。模块在服务端一次同步渲染，一次渲染里不存在「某个模块失败」；失败统一归页面级 Alert（Figma `140:3754`）。
3. 空值统一 **`—`（U+2014）**，`0` 只表示零，两者不许混。
4. `readonly` **整块剔除**不进公司汇总的模块。现在只有 `evidence_gallery` 一个（`MODULE_REGISTRY` 里唯一的 `aggregatable=False`，`app/oams/modules.py:249`）。理由：只读是**公司层看数**的视角，证据的链接是部门私有的、不出楼，给公司层看既无汇总意义，又多一层外泄面；**审核要看证据走 `preview`**（真实控件 `disabled`、证据区照常渲染），两个视角分工清楚。2026-10-30 改为按代码现状，先前「保留只读」那条作废。
5. 图标只 4 枚：`plus` / `trash-2` / `external-link` / `arrow-right`，不给每个模块配语义图标。
6. 表格编辑态走**单元格内联编辑**（高 28、聚焦才描边），行高从 42 收回 30。
7. 多列断点两档：**> 1100 原列数 / 900–1100 最多 2 列 / < 900 单列**；5 列退 **2 列**（不退 1 列）。
8. 模块块面底色改 **`bg/surface` 白**；`columns` / `rows` / `grid` 去掉边框 + 底色 + 内距，只做纯排版。

### 1.3 三状态

| 状态 | 定义 | 表现 |
| --- | --- | --- |
| 空 | 合法，但没数据（0 行 / 没绑定 / 没上传） | 一行 13 号 `text/muted`，模块高度不塌也不涨（≤48）；需要动作时后缀一句可点 |
| 不全 | 有数据，但字段缺（缺标题 / 缺日期 / 缺单位） | 占位文字，**不隐藏整行、不报错** |
| 有数据 | 满态 | 见各模块 |

**没有第四种状态。** 取数失败不下放到模块层（拍板 2），描述符配置错（缺列 / 未知 metric）由 `check` 与 preview 承担，不算空态——最容易混的是 `table`：`columns` 为空是配置错，不是空态，见 §3.1 第 9 行。

### 1.4 文案与符号

- 空态统一句式 **「还没有 X。」**（清单里 `rank_list` 的「暂无排行数据。」、`activity_feed` 的「暂无动态。」按此改写；模板原文见 §4.1 文案清单）。
- 字段缺的占位固定三个：**「未填写标题」「未排期」「未指定」**，其余一律 `—`。
- `—` 是 U+2014。**G5 已在代码里收口**：`render.py:226` 是 `EMPTY = "\u2014"`，`aggregate()`（`:497`）与 `format_number()`（`:229`）空值都返回 `EMPTY`，不再有 `--`；模板里剩下的 `&mdash;`（如 `progress_row.html:16`）渲染出来就是 `—`，等价，不用改。
- **空值与 0 必须分开**：未填的进度是 `—` + 空轨道，不是 0% + 空条。**G4 也已收口**：`progress_percent()`（`render.py:394-402`）空值返回 `None`，`progress_row.html:16` 已按 `{% if pct is none %}&mdash;{% endif %}` 分支。

### 1.5 图标

模块层现在**零图标**，且 `flow_strip.html:8` 拿 `&rarr;` 当箭头。收口口径（拍板 5）：只上 4 枚动作/方向图标，不给每个模块配语义装饰图标。

| 用途 | Lucide | 位置 | 尺寸 |

| 新增一行 / 一个节点 | `plus` | 表尾整行按钮左侧；里程碑列表末尾 | 16 |
| 删除一行 | `trash-2` | 行尾，hover / focus 时显 | 16 |
| 证据外链 | `external-link` | 链接文字右侧（替掉 `↗` 字符） | 16 |
| 流程方向 | `arrow-right` | 流程条段与段之间（替掉 `&rarr;`） | 16 |

规格照 `docs/design/design-system-v1.md` §5.1：24 网格、`stroke-width: 2`、圆头圆角、`stroke="currentColor"`、颜色取 `text/muted`，与 13 号正文基线对齐。**4 枚要先进 Figma `224:14183`，再在模板里内联同一份 path**（两处同源）。

### 1.6 断点、密度、底色

- 多列断点（拍板 7）：> 1100 原列数；900–1100 最多 2 列；< 900 单列。5 列在 900–1100 退 2 列，不退 1 列。
- 控件基准线 30；表格行高 30，编辑态单元格内联编辑高 28（拍板 6）。
- 有底块面 `bg/surface` 白（拍板 8）；`columns` / `rows` / `grid` 无框、无底色、无内距。
- 间距只有 4 / 8 / 12 / 16，`lg` 的 20 收成 16（G13）。
