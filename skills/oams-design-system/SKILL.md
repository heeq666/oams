# OAMS 设计规范（做界面前加载）

你在给 OAMS（组织内 AI 应用的宿主与应用商店）做界面。它的视觉口径是 **shadcn 的语义色 + 白底 / hairline 分界 / 五档圆角 / 无阴影 / 一个强调色**。你不需要、也不应该安装 shadcn/ui（它要 React + Tailwind，本项目是 FastAPI + Jinja2 + htmx 服务端渲染，无前端构建链）。

## 先读这两个

1. `docs/design/design-system-v1.md` —— 令牌表、三层结构（骨架层 / 组件层 / 模块层）与 38 个组件组 + 14 个模块组件、八条硬规则、验收清单。
2. `docs/design/tokens.json` —— 85 个令牌的机器可读值（Figma 导出）。

Figma 是唯一真源：页面 `0:1`（`02 · 组件库`），主库 frame `140:3438`（自上而下：骨架层 → 组件层 基础件 / 表单 / 反馈 / 数据 → 浮层 → 协作室 → 模块层）；页面稿全在 `03 · 页面稿`（`3:88`），组件库页只放组件。命名一律中文，变体属性名写作 `变体`。Figma 是 Starter 计划，只有 3 个页面，不要再 `createPage`。

## 令牌钩子（代码里用这些，不写字面值）

颜色：`--oams-bg` `--oams-bg-muted` `--oams-line` `--oams-line-strong` `--oams-ink` `--oams-muted` `--oams-accent` `--oams-hover`；状态 `--oams-done` `--oams-blocked` `--oams-decision`。
圆角按尺寸分档：容器 `26` / 中等块 `18`（含**输入框、下拉、文本域** —— 它们都长在卡片里）/ 行与高亮 `9`（菜单行、chip、侧栏行）/ 方框 `4` / 胶囊 `999` 只给按钮·搜索框·徽章·开关·页码（表格本体 0）。间距只记三个数：块与块 `16`、元素与元素 `12`、行内 `8`（**标签↔控件也是 8**，没有 6 这一档；Figma `Field 表单行` `140:3688` 两个变体 `itemSpacing` 都是 8，2026-10-31 撤销「6」）。控件基准线高 `30`（input / select / button 同高，内距 0·12），textarea 最小高 `120`。连续曲率（cornerSmoothing 0.6）只有 Figma 有，CSS 保持圆弧。字号：11~32，字重只有 Regular / Medium / Semibold。

## 八条硬规则（违反就是返工）

1. 只用令牌，不写字面 hex / 圆角 / 间距。
2. 圆角只从这五个值里取：容器 26 / 中等块 18（含输入框、下拉、文本域）/ 行与高亮 9 / 方框 4 / 胶囊 999（表格本体 0）。卡片里拉出来的浮层（下拉框展开层、卡片内菜单）用 18 —— 外层卡片已经是 26，同处不重复。胶囊 `999` 只给按钮、搜索框、徽章、开关、页码 —— **输入框/下拉/文本域写 18**（30 高的盒子上会自然渲染成胶囊，这是要的效果）。贴边嵌套取同心值 `内层 = 外层 − 内边距`（卡片 26 + 内距 16 → 行 9），内层圆角更小会「咬角」；日常照 `docs/design/design-system-v1.md` §3 那张表取，不用算。
3. 表面无阴影，分层靠 1px `border/default`；只有浮层（Modal / Menu / Tooltip）允许极淡投影。
4. 一个强调色：一屏只有一处主动作（`accent/default`），次要动作白底 + hairline。
5. 状态色只表达状态，不装饰。
6. 表格单行：行高 30（6/8 内距 + 18 行盒 + 1px 线），超宽省略号，不缩字号。
7. 控件四态齐全：default / hover / focus / disabled；表格行 default / hover / selected。
8. 指标数值 `Display/Metric`，单位小一号且 `text/muted`，金额与数量右对齐。

## 工作流程

1. **先找现成的**：38 个组件组 + 14 个模块组件（模块层 `148:5948`，与 `MODULE_REGISTRY` 的 21 个 key 一一对应）里有的，直接复用 Figma 实例 / 对应模板片段，不要重画。
2. **先判断属于哪一层**：骨架层（页面外壳）/ 组件层（卡片面板里的控件与数据件）/ 浮层（Modal、Menu、Tooltip）/ 协作室（右下角圆按钮呼出的全局讨论层，底部两栏弹层，分「管理群 / 汇报群 / 私聊」）/ 模块层（与 `MODULE_REGISTRY` 的 21 个 key 对齐的内容块）。新组件先归类再落位。
3. **改 Figma 再改代码**：视觉改动先落到 `0:1` 页，再改 `app/oams/static/oams-modules.css` 与模板。
4. **三档截图自检**：1440 / 1024 / 768，窄屏不许横向滚动。
5. **对照验收清单**：见 `docs/design/design-system-v1.md` §10。

## 反面模式

- 引 shadcn/ui 的 React 组件或 tailwind 类名 → 本项目没有构建链，直接废。
- 为「好看」加渐变、玻璃拟态、彩色大面积 → 与口径冲突。
- 自己发明 6px / 8px / 12px / 16px / 24px 圆角 → 五个值之外不允许。
- 用 `padding` 凑控件高度（`padding: 9px 12px` 算出 36 与 35.5 两种高）→ 控件一律 `height: 30px; padding: 0 12px`。
- 把输入框写成 `999` → 输入框走 `18`；30 高时 18 会被截到 15、渲染成胶囊（这是要的），但值别写 999 —— 高度一变它就不是胶囊了。
- 间距写 10 / 14 / 18 → 只有 16 / 12 / 8（+6）。
- 卡片用 18px 圆角 → 一律 26；菜单行 / chip / 侧栏行用 18 → 一律 9（只有输入框、下拉、文本域是 18）。
- 行高亮贴着弹层圆角（26 外框 + 内距只有 8）→ 内距加到 16，而不是把行高亮的圆角调小。
- 表格靠缩字号塞进列宽 → 应该省略号或加宽列。
- 未读徽章只给 HUG 不给 `min-width` → 会被挤成 7×16 的窄椭圆。固定 16 高、min-width 16、左右内距 4，一位 16 / 两位 20 / 「99+」28，只放数字。
- 带白环的小圆点用 INSIDE 描边 → 红区被抠掉两倍描边（16 剩 14、8 剩 4×4）。白环一律 OUTSIDE（入口徽标 1.5、提及点 2），徽标里的文字 `textAutoResize` 必须是 `WIDTH_AND_HEIGHT`。
- 图标按钮里直接打字符（`⌄` `⤢` `‹` `✕` `⌕`）→ 字重和笔画跟着字体走，13 号正文旁边又小又虚，缺字还会退化成方框。一律 32 见方按钮 + 18 见方 SVG。
- 手画图标、或两家库混着用（同一个气泡两版、描边 1.4 与 1.7 混用）→ 一律 Lucide（ISC，24 网格、`stroke-width:2`、圆头圆角、`fill:none`），Figma 组件库 `图标 · Lucide（ISC）`（`224:14183`）+ 模板内联同一份 path；颜色走 `currentColor`，不在 SVG 里写死。见 `docs/design/design-system-v1.md` §5.1。
- 弹层顶上叠两层额头（面板头 + 内容头）→ 白丢 100 高、并排两个标题。压成一条 52：左搜索右标题，各自带下边线连成一条横线；弹层自己的名字降到栏底当脚注。
- 输入框外面再加一条通栏分隔线 → 输入框本身就是描边胶囊，已经是分界；两层分界把白的消息区切碎。
- 右栏换个会话就顺手把左栏按默认视图重刷 → 在通讯录里点一个人，左栏被弹回会话列表，等于赶人走。左栏取哪一份由 `data-collab-view` 决定，右栏只负责触发重取、不负责决定内容。
- 列表一次全量下发（几十人以上就是几十 KB 塞在首包里）→ 分片发，一窗 20 行 + 一行「加载更多」。分片时分组标题要接力（上一窗最后一行属于哪组，下一窗第一行就不再画标题），否则滚动加载处冒出第二个「同事」。
- 长列表分片用 htmx 的 `hx-trigger="revealed"` 当哨兵 → htmx 1.9.12 把「尺寸为 0」也算露出来了，藏在 `display:none` 那一栏里的哨兵会在面板一打开就把整份名单拉完。自己开 `IntersectionObserver`（root = 那个滚动容器），隐藏时没有交集。
- 重取已经滚过几窗的列表时只取第一窗 → 人滚到一半的名册被缩回去。重取带上 `limit=已经滚出来的行数`。
- 用岗位名判断谁是管理员 → 「负责人」是 title 字段，谁都能写。分组只看授权（与 `admin_level` 同一份 `ADMIN_RESOURCES`）。
- 左栏那种 `bg/subtle` 底子上的图标按钮，悬停/选中还用 `subtle` → 看不出按没按下。选中给 `bg/surface` 白底 + `text/primary` 深图标。
- 把组名换个说法再解释一遍（「管理群 — 管理员之间谈页面怎么搭」「私聊 — 两个人的对话」）→ 读者认得字，解释等于噪声。分组标题只写组名。
- 会话行第二行拿模板句占位（「部门管理员在这里讨论页面怎么搭」「私聊」）→ 第二行只放真实的最后一条消息；没消息就只显示名字，行还是 56 高、垂直居中。
- 群头标题写成「设计部打样进度 · 汇报群」→ 类型由旁边那枚 Badge 说，标题里再写一遍是重复。左栏没有徽章的行才带「· 管理群」后缀。
- 同一句话在两个地方各说一遍（空态说「和你停在哪个页面无关」、脚注再说一遍）→ 留一处。判断标准：删掉之后读者是否还知道该干什么——知道就删。
- 切视图 / 切 tab 这种本地动作也去取一次网络 → 点下去列表还是旧的，近半秒后突然换掉，人以为按钮坏了。两份内容都发下来，切换只翻属性 + CSS 显隐；只有真正要新数据（搜索、打开会话）才请求。
- 两态按钮只换 `aria-pressed` 的底色不换图形 → 底色差一档，看不出「已经切过去了」。图形跟着换（去哪儿 / 回哪儿）。
- 头像里塞名字首字（群取群名、人取名）→ 撞字撞得厉害：「设计部 · 管理群」「设计部打样进度 · 汇报群」都是「设」，一列里几行长得一模一样；一个人的「张」也说不清是哪个张。**头像一律图标**：群 `users`、人 `user`（18、`text/secondary`，形状再分圆角方块 / 圆形），身份交给旁边的名字。
